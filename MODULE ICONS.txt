======================================================================
 MODULE ICONS - every icon a Forge module can use
======================================================================

Both mods share one icon namespace, so this list covers Weapon Forge
module "icon" and Module Forge "icon" alike. Type the NAME:

    "module": { "icon": "HUD_GridTiles_13" }      Weapon Forge
    "icon": "HUD_GridTiles_13"                    Module Forge

There are 81: 45 HUD_GridTiles and 36 HUD_Modules.

HOW TO SEE THEM. The number tells you nothing about the picture, so
open "Module Icons.html" next to this file - it draws all 81 at size
with their names, filters by name or by which stock module uses them,
and copies a name when you click it. This text list is for reference
once you know what you are looking for.

SIZE. Stock icons are 24x24 (a few 22x22) at 40 pixels per unit - NOT
the 20 the rest of the game's art uses. Your own PNG can be any size;
it is rebuilt to the stock footprint for you. Draw it SQUARE: the
module card stretches art to a square without preserving aspect,
while the pickup lying on the ground keeps its shape.

COLOUR. An icon is TINTED by the module's colour in both places it is
drawn, so draw it white or grey and let "color" do the work - or set
the colour to "#ffffff" to see the art's own colours.

A NAME CLASH GOES TO THE GAME. If one of your own sprites shares a
name with a game sprite, the game's wins and the log says so. Rename
yours.

PICKING A FRAME. "HUD_GridTiles_4:2" takes frame 2 of a numbered run.
An icon cannot animate - nothing ever ticks it - so the suffix is a
frame PICKER here rather than a flipbook.

----------------------------------------------------------------------
 WHERE THIS CAME FROM
----------------------------------------------------------------------

Generated by reading the game's own assets: every HUD_GridTiles_* and
HUD_Modules_* sprite, and every module asset referencing one via its
"icon" field. The mapping above is the game's, not a guess, and it is
regenerable when the game updates.

The icon ART is deliberately NOT included, here or in the HTML - it
belongs to the game and these repos are public. The HTML draws it out
of your own copy of the atlas instead; it tells you which file.
