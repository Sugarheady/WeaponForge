MODULE ICONS — all 81 of them

Every icon a Forge module can name. Both mods share one icon namespace, so this covers Weapon Forge's module.icon and Module Forge's icon alike. Click any icon to copy its name.

The art is not in this file. These icons belong to the game, and these repos are public, so this page ships no copies of them — it draws them out of your own atlas instead. Point it at:
sactx-0-1024x512-Uncompressed-Atlas UI-9d06dca2.png
found in EXPORT/ExportedProject/Assets/Texture2D/. Nothing leaves your machine and this page makes no network requests of any kind. The names and the usage list below work with or without it. Tip: copy that PNG next to this file as atlas.png and it loads by itself every time.
Drop the atlas PNG here, or click to browse.

Draw your own square. Stock icons are 24×24 at 40 pixels per unit — not the 20 the rest of the game uses. Any size works (it is rebuilt to the stock footprint for you), but the module card stretches art to a square without preserving aspect, while the pickup on the ground keeps its shape.

Icons are tinted by the module's colour in both places they are drawn, so draw white or grey and let color do the work — or set the colour to #ffffff to see your art's own colours.

An icon cannot animate — nothing ever ticks it. You can still choose which frame of a run it shows: HUD_GridTiles_4:2 takes frame 2.

The icon→module mapping is read out of the game's own assets rather than guessed, so it is regenerable when the game updates. MODULE ICONS.txt beside this file has the same list in plain text.
