LOADOUT BUILDER

Start a run with up to five things already equipped. This makes one .json for the loadouts folder next to WeaponForge.dll — the folder beside weapons, not inside it. Each file is one card on the ship-select screen.

The card

The five slots

Fill 1 to 5. Leave the rest empty. Pick from the list or type a name: one of your weapon files' "name", a stock module like Module Weapon White Shotgun, or the name on its card like SHOTGUN. Weapons go in primary/secondary, gadgets (and drones) go in gadget1–3 — the game refuses anything else.
primaryleft click · weapons
secondaryright click · weapons
gadget1key 1 (and Ctrl) · gadgets
gadget2key 2 · gadgets
gadget3key 3 · gadgets

Your weapons (optional)

Pick the .json files from your weapons folder (Ctrl+A in the file dialog selects them all). Nothing is uploaded — the page just reads each file's name and slot so it can offer them in the lists above and tell you if one is in the wrong kind of slot. You can also just type the names.

Presets

Stock modules only, so each works on any install. Swap any slot for one of yours.

    Good to know
    
    • Any of your weapons can go in a loadout, even
    one whose file says "source": "loot" or "none" —
    a loadout is how you start with a loot-only gun.
    
    • The ship itself (the embedded core) is the same on every card, so
    there is nothing to pick for it.
    
    • A loadout only decides what you START with. After that the modules
    are ordinary equipment: they save, load, and can be swapped like any other.
    
    • Only the five weapon/gadget slots, on purpose: a loadout is a starting
    setup of weapons and gadgets that work well together. Upgrade modules on the
    rest of the grid are not part of it.
    
    • A name that is not found, or is in the wrong kind of slot, leaves that
    slot empty and says why in BepInEx\WeaponForge.log (search
    loadouts/). A file where nothing resolves gets no card at all.
